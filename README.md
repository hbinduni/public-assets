## Adding files

- Put each project or collection in its own descriptive folder.
- Use stable filenames for externally referenced assets. For incompatible changes, add a versioned folder instead of removing existing files.
- Keep published URLs available while external consumers depend on them.
- Publish only files intended for unrestricted public access. Keep credentials, private keys, customer data and private application source elsewhere.
- Record an asset's purpose and origin in its folder README. Publication does not grant additional rights to third-party names or marks.

Raw URLs follow `https://raw.githubusercontent.com/hbinduni/public-assets/main/<folder>/<file>`.
